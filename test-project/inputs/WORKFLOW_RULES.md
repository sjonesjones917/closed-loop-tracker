# Closed-Loop Outcome Rules

Requirement outcomes: SATISFIED, VIOLATED, UNDETERMINED.

Factual absence values: UNKNOWN, NONE, NOT APPLICABLE.

Release outcomes: ACCEPTED, REJECTED, BLOCKED.

ACCEPTED requires affirmative evidence for every mandatory requirement and successful mandatory validation. REJECTED applies when a mandatory requirement is demonstrably violated. BLOCKED applies when a mandatory requirement cannot be established because required evidence, authority, input, or capability is unavailable.
