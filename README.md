# Mobile Closed-Loop Agent Reliability Workbook

This repository contains one application only: `index.html`.

The application implements the controlling 30-stage workflow, phone-first stage records, stage-specific copy blocks, explicit stage gates, immutable job snapshots, SHA-256 evidence controls, the required phone folder/filename conventions, and Appendices A–F.

There are no alternate application versions, legacy payloads, repair applications, self-build applications, or versioned HTML entry points in the live repository tree.

GitHub Pages deployment is performed by `.github/workflows/pages.yml`.
